# Quantum Superposition Demo
============================

A beginner-friendly Qiskit project showing superposition and measurement for a single qubit.

## Physics idea
A Hadamard gate creates the state:

|\psi⟩ = (|0⟩ + |1⟩)/√2

Measuring this state repeatedly gives about 50% |0⟩ and 50% |1⟩.

## Skills shown
- Qiskit circuit construction
- quantum measurement
- simulator usage
- histogram visualization
